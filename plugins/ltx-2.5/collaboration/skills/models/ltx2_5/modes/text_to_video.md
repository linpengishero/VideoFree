# LTX 2.5 Text to Video

Default to one continuous shot. Put the main visible action early, then develop it chronologically through framing, setting, character identifiers, camera movement, coherent light, and synchronized sound. Use 4–8 present-tense sentences. Only use 2–4 native cuts when the user explicitly requests multiple shots; name every transition and re-establish the scene after it. Default to no dialogue unless exact words are supplied.
