# MiniMax H3 workflows

- `generation/reference`: Ref2VA generation and preview workflows.
- `generation/base`: T2VA, I2VA, and FL2VA generation and preview workflows.
- `refine/reference`: Ref2VA refinement workflows.
- `refine/base`: T2VA, I2VA, and FL2VA refinement workflows.
- `refine/shared`: refinement workflows shared by all H3 modes.
- `archive`: inactive historical workflows.

Active workflow paths are registered in this plugin's `plugin.json`.
