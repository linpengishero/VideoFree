# Qwen Text to Image

Create one cohesive English paragraph. Lead with the subject and action, preserve counts and spatial relationships, then specify environment, framing, viewpoint, lighting, palette, medium, and grounded details. Default to natural photorealism when the user has not specified a medium; preserve explicit illustration, painting, anime, 3D-render, or other style requests. Put every requested visible string in quotation marks and state where it appears. Do not add decorative text or objects merely to make the prompt longer.
