# 发布检查记录

检查日期：2026-10-16。面向单进程、家庭或小团队部署；备份目录不在检查范围内。

## 本轮修复

- 重新生成弹框：模型、模式和服务使用紧凑摘要；插件参数统一标签与控件布局，桌面三列、手机两列。
- 直接生成的幂等键按项目隔离，串行处理同键并发提交，校验请求指纹；同键不同请求返回冲突。
- 协作提交的幂等键加入项目范围，避免不同项目相互命中。
- V2 任务列表不再先截取 500 条，分页可以访问更早的任务。
- 项目创建提前验证 Windows 保留名及输出目录；目录准备失败不写项目记录，数据库插入失败清理空目录。
- 删除旧静态首页回退、无人调用的旧路由导出层和核心音乐预设目录实现；缺少前端构建返回明确错误。
- 模型专用设置缺省值、预设、校验与提示词组合归插件声明；框架不再维护这些字段的模型专用白名单。
- 语音提交保留显式能力 ID、插件参数和设置快照，按注册信息执行原生或 ComfyUI 任务，不再依赖固定能力 ID。
- 修复声明式语音任务恢复时参考音频字段错位，以及云端语音任务恢复后被误判为本地执行的问题。
- 比例和分辨率按通用规则解析，插件可声明自定义比例及 P/K 分辨率，不再受旧枚举白名单限制；最终尺寸仍受请求安全范围约束。
- 生成能力必须注册到模型菜单，或明确声明 `ui_hidden: true`；移除框架按固定能力 ID 隐藏菜单的逻辑，避免插件静默消失。
- `启动VideoFree.cmd --check` 检查应用导入、插件清单、前端构建 manifest、动态 JS/CSS 及依赖文件、应用插件入口和 socket/SSL/SQLite 运行库；检查失败返回非零退出码，不探测 ComfyUI。
- 重启按当前插件能力恢复全部排队协作，不再限定旧的 `studio.*` ID；执行中、能力已移除或恢复队列已满的协作标记中断，不遗留无法执行的排队记录。
- 两种协作提交入口入队失败均标记失败；相同幂等请求可重试入队，同键并发只入队一次，成功后清除入队失败标记。
- 独立协作入口的 quick 模式正确选择 compile，并保存插件 ID、版本和修订快照；插件更新后拒绝确认旧修订。
- 忙碌、已取消或已提交会话拒绝消息时不写入历史；重新生成必须携带原任务的能力标识，不再按模型或模式猜测。

## 打包要求与边界

- 本轮未提交或推送 Git。发布时须包含新增的 `plugins/`、后端与前端源码、测试、文档、Python 依赖及重新构建的 `static/dist/`，不能只打包已被 Git 跟踪的旧文件。
- 完整安装包必须包含 `runtime/`；源码部署须按依赖清单安装环境并构建前端。建议在实际发布包解压后再次运行 `--check`。
- 前端发布包必须包含构建生成的 `static/dist/.vite/manifest.json` 和全部分块资源；不要因目录以点开头而漏打包。
- 不发布本地 `.env`、插件 `.env`、`data/`、备份或缓存。插件密钥由使用者在设置页填写。
- 旧 `commuity/`、`backups/`、`备份/`、`agent_skills/` 和插件归档工作流已清理；发布包不得重新带入这些旧实现或本机缓存。
- Python 插件为可信本地代码，不是安全沙箱。应用插件的 Vue 页面在插件目录内独立构建到 `ui/dist/`，不需要重新构建主前端；纯声明式生成插件不需要专用 Vue 页面。
- 旧模型生成、专用 TTS、refine、H3 翻译和 studio 协作协议入口已删除；前端、MCP 统一使用当前生成、协作与插件动作协议。旧客户端必须更新，不保留兼容转发；现行项目、上传及任务管理接口保留。新增控件类型仍需要扩展框架渲染器。
- 幂等并发锁适用于单进程；不承诺多进程锁或提交成功但尚未写入幂等记录时发生进程崩溃的恰好一次语义。
- 已执行使用合成素材的 FFmpeg/OpenMontage 渲染回归；未进行真实 GPU、云端计费生成或用户完整成片验收。发布自检不代表所有使用者的 ComfyUI 节点和模型均已安装。
- 当前结论针对本仓库的单进程部署；尚未完成实际发布压缩包或干净检出环境的验收。

正式发布前必须将当前新增源码、插件、测试、文档、依赖和构建资源纳入版本控制，并在新的干净目录执行 CI 同款编译、测试、前端构建和 `--check`；脏工作区中的通过结果不能替代干净检出验收。

## 插件边界收口（成片暂缓）

- 公共提示词移除 H3/Qwen 专用规则；H3 自带完整系统提示词，Qwen 四格要求归其模式技能。
- 删除框架旧工作流输入适配，节点识别由对应插件编译器负责；Krea2 风格节点转换不再影响其他插件。
- Krea2 通过 PluginRuntime 查询风格目录，不再导入 generation service；风格库路径和分类前缀由插件声明。
- 音乐与检查点绑定默认值归插件清单；框架请求默认值、重新生成及状态接口不再预选具体模型或音色。
- 修正 LTX 插件模板自身的 PrimitiveInt 类型，不再给所有插件全局重命名 PrimitiveNode。
- 任务编辑器根据插件的 prompt_translation_action 声明调用译稿动作，不再写死 H3 动作 ID；无声明时隐藏直接翻译。
- 成片业务本轮不扩展；发布时仍需单独核对 `plugins/film-studio/` 内置工具、第三方许可证和真实渲染环境。
- Git 未跟踪源码、依赖、MP3 与前端分块仍须纳入发布清单；本轮不自动暂存、提交或推送用户改动，正式发布门槛仍未全部满足。
- CosyVoice3 固定 MP3 的来源和再分发授权须由维护者确认；文件已正确随插件声明，但目录归属正确不代表获得第三方音频授权。

## 最新发布复核（2026-10-18）

本节取代上面的历史测试结论。

- 协作 worker 与参考素材持久化已移出 HTTP 路由；协作和生成共用的上传/data URL 解析归 `modules/shared`，不再跨域借用 `TaskStore`。
- `ApplicationContext` 由 bootstrap 组合根创建；core 不再在运行时导入 persistence，HTTP 不再直接导入 integration，共享请求契约归 core。
- 插件和业务模块通过 `GatewayError`/`PluginError` 报告业务错误，由 HTTP 边界统一转换，不再依赖 FastAPI。
- V2 router 显式接收 context，已删除未使用的路径和 handler 参数；新增边界回归测试防止 FastAPI、integration 和 TaskStore 反向依赖重新出现。
- 新增 Windows CI、最小 Ruff 阻断规则和独立开发依赖；CI 执行编译、后端与成片测试、前端构建和发布自检。

验证结果：Ruff 通过，264 项后端测试通过，40 项成片引擎测试通过，前端构建通过；`启动VideoFree.cmd --check` 检出 13 个插件并通过前端资源、socket、SSL、SQLite 与运行库自检。

当前剩余发布门槛：

- 当前工作区包含大量尚未纳入版本控制的新插件、源码、MP3、依赖及构建分块；必须完整提交后做一次干净检出或最终安装包验收。
- 未执行真实 GPU、云端计费生成和完整浏览器人工验收；自检不验证用户 ComfyUI 的全部节点与模型。
- CosyVoice3 固定音频的再分发授权仍须由维护者确认。
