# videofree 成片合成与交付设计

更新：2026-10-16。状态：成片已迁入 `plugins/film-studio/` 应用插件；基础合成、持久化、六阶段进度和工作台均通过通用注册加载。

## 已实现：基础合成与制作进度

- 视频生成完成不代表入选。视频编辑页右下角由插件注册“添加到成片”扩展，选择当前项目的目标成片或新建成片，确认后追加镜头并原子保存插件入选标记；不会启动合成。重复添加同一产物不会重复插入，合成中的成片不可添加。新视频不会继承旧视频入选标记，历史已入选数据保留。
- 当前项目的成片页只展示主动入选的视频，可创建多部成片，分别保存镜头顺序、入出点、逐镜头原声开关、单条背景音轨及其音量、尺寸、帧率、留边或裁切方式。
- 六个大阶段：文案定稿、公共资产准备、分镜与素材生成、审核与增强、剪辑合成、成片验收。不设置小阶段。外部 AI 通过通用插件动作上报阶段及备注，工作台每三秒更新；没有上报则显示未开始，不推测远端进度。
- 剪辑合成阶段只能由真实渲染任务更新；实际成功后才允许验收。保存编辑后重置合成和验收，历史成功版本仍可下载。
- 网关在独立子进程调用随仓库提供的 OpenMontage `VideoCompose`，保留第三方源码与许可证，不需要用户单独安装 OpenMontage 应用；需已有 FFmpeg/ffprobe 在 PATH。缺依赖仅在提交合成时提示，不影响一键启动及现有媒体生成。
- 独立 CPU 合成通道默认串行，不进入 ComfyUI 生成队列。网关关闭时回收子进程树；下次启动将中断的合成标为失败，不自动重跑。
- 所有引用必须是当前项目已归档产物，不接受外部任意路径、URL、命令或脚本。裁剪以实际媒体时长校验。合成中禁止删除涉及的源任务、分类、项目和成片。
- 输出目录：`data/projects/<项目目录>/films/<film_id>/<render_id>/`。每次保存 `plan.json`、`render.log`，成功后将临时 MP4 原子改名为 `final.mp4`。资源扫描只纳入最终文件，不暴露过程片段。删除成片清理其输出而不删除源素材；删除项目一并清理。
- 状态保存在框架通用 `plugin_documents` 表的 `film-studio` 命名空间，入选标记在 `plugin_job_marks`。启动时一次性迁移旧 `films` 表并删除旧表，旧入选字段仅用于迁移。已成功版本保留当时方案和下载 URL。源任务后续删除会从当前草稿移除引用并要求重新合成，既有成片文件与历史版本保留。
- 当前仅基础视频裁剪拼接及音轨混合，无多轨时间线、字幕编辑、转场、Remotion/HyperFrames、手动取消或远端工程同步。MCP 通过通用动作接口支持成片，不增加成片专用工具。

### 通用动作调用契约

以下操作都使用显式项目 ID，不改变工作台激活项目；现有生成接口不变。

| 动作 ID | inputs / 作用 |
| --- | --- |
| `film.select-source` | `{job_id,selected}`，仅设置候选标记 |
| `film.sources` | `{}`，查询当前项目入选且完成的视频 |
| `film.list` | `{}`，查询成片列表 |
| `film.save` | `{plan,film_id?}`，创建或部分更新方案；更新时省略字段保留原值 |
| `film.get` | `{film_id}`，读取详情与进度 |
| `film.add-clip` | `{film_id,clip}`，追加 Clip 并标记入选，不启动合成 |
| `film.progress` | `{film_id,progress:{stage,status,note?}}`，上报大阶段 |
| `film.render` | `{film_id}`，异步合成，轮询 `film.get` |
| `film.delete` | `{film_id}`，仅工作台可用，不向外部 AI 开放 |

HTTP 入口是 `POST /api/v2/plugin-actions/<动作ID>/execute`，请求体为 `{project_id,inputs}`。
MCP 使用 `list_plugin_actions` / `get_plugin_action` 发现契约，再调用 `run_plugin_action`，参数为 `{action_id,project_id,inputs}`。旧成片专用 REST 路由已移除。
动作返回 `{action_id,status:"completed",result:...}`，外层 completed 只代表命令已处理。合成必须查询 `result.render.status`，不能把外层状态或 HTTP 202 当成合成成功。

创建或保存方案示例（`artifact_index` 对应任务 `artifacts` 数组索引）：

```json
{"name":"第一集","clips":[{"job_id":"video-example","artifact_index":0,"in":0,"out":8,"original":true}],"bgm_job_id":null,"volume":18,"width":1920,"height":1080,"fps":30,"fit":"contain"}
```

阶段上报示例：`{"stage":"writing","status":"completed","note":"剧本审核通过"}`。
stage 可选 writing/assets/generation/review/acceptance；composition 由网关维护。
status 可选 pending/running/completed/failed/blocked。验收完成必须已有真实成功产物。
宽高分别支持 720/1080/1280/1920，帧率支持 24/25/30/60；背景音轨为同项目 music/tts 任务首个音频产物，短音轨循环至成片结束。
查询响应的 `render.status` 为 draft/queued/running/completed/failed；`render.progress` 为百分比，失败看 `render.error`，成功看 `render.url`，历史成功版本在 `renders` 数组。
参数错误返回 422，进行中操作冲突返回 409。

### 插件与框架边界

`plugin.json.application` 注册项目导航页面、资源编辑扩展、入选标签及输出筛选。页面在 `ui/`，方案校验、动作处理、合成适配在同一插件目录。框架不按成片 ID 或视频模型名分支。
框架 `ApplicationRuntime` 提供项目隔离、文档/引用存储、标记、项目目录、任务和串行信号量；不提供成片语义。启动恢复由插件钩子完成，框架只回收进程任务及重置不可能跨进程存活的占用状态。
禁用/移除插件会隐藏入口和动作，不删除已有文档与输出；重新启用可恢复。插件界面为本地可信 Vue 源码，新增或修改后需要重新运行前端构建；本次发布已构建。

## 当前实施：项目内一级分类

用户最终选择不增加作品集层级，保留原项目模型，在项目内增加一级分类。
旧任务通过数据库字段迁移归默认分类（`category_id=""`），不移动已有文件。
分类支持创建、改名、删除；素材归属在提交时确定，不提供移动入口或接口。后台保留空分类兼容旧资源，界面不显示默认分类入口，默认打开全部素材。
分类栏保持单行，根据可用宽度最多显示5个分类，其余通过可搜索下拉列表选择和管理。
删除分类会真实删除该分类的任务、项目产物和任务包；其他分类与公共资产不受影响。清空操作只清空当前筛选范围，全部素材视图标注清空项目素材。
有进行中的生成或协作任务时先完成或取消，再删除分类。
生成提交时固定分类，二采、分割、后处理和重新生成继承源任务当前分类。
REST/MCP 的 `category_id` 为可选项，不传则归默认分类；原接口行为不变。
数据库是分类归属的唯一依据，任务 manifest 中分类仅记录提交时快照。
`/studio?view=collections-preview` 已回到真实项目页，不再加载作品集演示。
成片当前实现见本文开头；分类与公共资产仍独立于成片合成计划。

### 公共资产档案库

每个项目自带公共资产入口，不是用户分类，入口不能改名或删除。旧素材不自动迁移。
类型包括人物、场景、道具、配乐、音效、其他；名称必填，详细描述可编辑，可先建文字档案再补文件。
人物可关联一张角色板（character_sheet）和一段角色声音（character_voice）；二者独立上传、选取与引用，不会自动捆绑提交。声音不再编辑对应文字，历史 transcript 原样保留。场景和道具关联图片；配乐和音效关联音频；其他支持图片、视频和音频。
选取已有素材使用独立弹框，支持素材名称搜索、分类与媒体类型筛选，每页48项。点击缩略图选择，独立放大按钮预览，声音通过播放按钮试听，确认后才添加。角色板入口只接受图片，声音入口只接受音频。上传入口统一使用加号文件格。

相关前端唯一实现：MediaDialog 管理原生模态层和关闭行为，MediaPreview 管理图片/视频/音频预览，MediaTile 管理缩略图、选择和试听。公共资产、本地资源与参考上传复用这些组件；不要继续添加平行预览弹框或叠加覆盖样式。

资产列表展示封面、名称与两行设定摘要，右上角图标进入编辑；点击卡片打开只读资产详情，展示完整设定与全部关联素材，图片点击放大，声音点击试听。编辑表单中的素材使用 64×54 缩略图紧凑行，上传加号同尺寸；不再显示独立播放或放大按钮。素材选择弹框仍保留独立预览，避免与点击选择冲突。
公共资产保存到项目目录的 `public-assets/<asset_id>/`，从已有素材归档时独立复制，不改变原素材分类。
公共资产页面支持筛选、搜索、详情、上传、选取已有项目素材、图片放大、音频试听和引用。
资源抽屉提供公共资产入口，按人物、场景、道具、配乐、音效等资产类型筛选，点击资产后再选取其内部文件，不把所有文件按媒体类型混排；引用经现有上传与任务快照保存流程，不把文字设定机械拼接进提示词。
REST 为 `/v1/projects/{project_id}/public-assets` 及子路径；MCP `list_public_assets` 只读返回档案、文字设定和媒体URL。
公共资产不混入普通文件列表；清空生成任务不删除公共资产，删除项目会一起删除。
删除档案或文件会检查任务与协作的直接路径/URL引用；已经上传并进入任务包的副本独立保存。
本次不新增资产自动生成代理、自动绑定或成片依赖系统，先生成再显式选入档案。

## 历史提案：作品集（已放弃）

以下为讨论记录，不是当前实现。

- 可选作品集作为项目的上级；项目继续代表一集或一次独立制作。不采用无限嵌套。
- 工作空间展示作品集与全部项目，可单独筛选独立项目。
- 创建作品集填写名称和简介，创建后进入作品集，显示项目、公共资产两个页签。
- 创建项目时选择归属作品集，默认当前作品集；选“无”则为独立项目。

- 一个项目对应独立 OpenMontage 生产记录。进度应复用 Backlot 的检查点、事件和分镜状态，不另建重复的阶段系统；远端智能体的生产目录需建立受控同步或连接。

后续实现时，本文原有“同项目资产”的约束需明确扩展为“本项目资产或所属作品集的公共资产指定版本”，不能放开任意跨项目引用。作品集与原网关项目 ID 显式关联；移动项目前检查公共资产依赖，不允许无提示破坏既有成片引用。

## 历史完整规划（不等于当前已实现）

以下各节保留早期设计记录；实施范围、接口与状态以本文开头为准。

## 1. 目标与边界

将人工剪辑和 AI 自动制作的最终视频统一纳入项目：能查看、播放、审核、下载，能追溯使用的素材、合成参数和版本。AI 不能只在自己的工作目录生成一个用户看不到的文件就宣布完成。

复用 OpenMontage 的专业合成能力，不自行另写 FFmpeg 合成引擎，不将现有素材生成工作流替换为合成工作流。ComfyUI 仍负责生成，网关负责项目管理、合成编排和交付归档。

本次仅实现前端预览，不新增合成 API、数据库表、渲染进程或真实合成任务。示例状态不代表后台任务。暂存只存在当前组件内存，刷新或离开成片视图后不保留。

## 2. 界面

项目内增加“素材 / 成片”切换，保留现有素材画布及生成操作栏。

### 成片列表

- 展示名称、封面、时长、来源（AI / 手动）、版本、更新时间和状态。
- 按名称搜索，按未提交、待审核、已交付筛选。
- 新建合成、打开已有合成、查看版本；正式版本增加真实进度、失败原因、重试和下载。
- 默认只展示当前项目，禁止混入其他项目产物。

### 合成编辑页

- 左侧：项目视频、声音和音乐素材，添加到合成方案。
- 中间：预览播放器，镜头列表支持拖动排序、前移后移、移除、入出点和原声开关。
- 右侧：配乐与音量、输出分辨率 / 帧率 / 画面适配、技术检查、内容审核和交付。
- 顶部：成片名称、来源、版本、保存草稿、提交合成。
- 窄屏改为纵向布局，素材横向滚动，设置区下移。

预览入口：`/studio?view=films-preview`。示例封面与演示视频分别标识；播放器播放单个源镜头，不冒充合成结果。声音设置和裁剪参数仅编辑方案，不在浏览器内伪造混音或完整合成预览。真实合成和交付按钮禁用。

## 3. 数据对象和状态

| 对象 | 职责 |
| --- | --- |
| Film | 项目内成片身份、名称、当前草稿、交付版本 |
| FilmVersion | 提交时冻结的合成方案及素材引用，不可原地覆盖 |
| RenderTask | 对某一版本的一次渲染尝试、进度、日志、取消与错误 |
| Review | 技术校验结果及人工 / AI 内容审核结论 |
| Artifact | 已归档成片文件、缩略图、元数据与下载入口 |

草稿可修改；每次提交冻结新版本。重试是同一版本的新任务，修改方案则创建新版本。渲染状态与审核状态独立：文件生成成功不等于审核通过，更不等于已交付。

任务状态：queued → running → completed / failed / cancelled。审核状态：pending → approved / rejected。交付只能指向已归档且审核通过的版本。

## 4. 合成方案

方案使用结构化数据，包含 schema_version、project_id、film_id、镜头、声音和输出参数，不接受任意服务器路径、命令或脚本。

- 镜头：asset_id、顺序、trim_start、trim_end、原声保留及音量。
- 声音：旁白 / 配乐 asset_id、起始时间、裁剪范围、音量、淡入淡出、循环策略。
- 输出：宽高、帧率、contain / cover、编码格式。
- 附加：制作说明、关联定稿文档和预期时长。

引用必须属于同一个项目。提交前检查文件存在、音视频可解码、入出点有效、输出尺寸和总时长在限制内；实际时长以媒体探测结果为准，不相信客户端填写值。

## 5. 统一流程

1. 人工或 AI 完成文案和素材审核。
2. 通过同一业务服务创建成片草稿，引用网关 asset_id。
3. 校验方案、冻结版本，以幂等键创建异步合成任务。
4. 渲染适配器调用 OpenMontage 的 video_compose、audio_mixer 等原生能力。
5. 检查视频流、时长、尺寸、帧率、音轨及文件完整性，归档到项目。
6. 工作台和 AI 获取同一份任务状态和产物；完成内容审核后标记交付。

AI 只能在产物已归档、校验通过且结果可获取时宣告交付。外部已经合成的视频可另设“导入成片”，但必须标记外部来源；没有方案则不得声称可重现。

## 6. 架构归属

- `frontend/src/components/FilmStudio.vue`：当前预览组件，后续按实际复杂度拆分。
- `backend/modules/composition/`：实施阶段放置成片、版本、校验和任务编排。
- `backend/integrations/`：OpenMontage 适配与受控子进程执行，隔离第三方运行环境。
- `backend/persistence/`：成片、版本、任务与审核记录的数据访问。
- `backend/interfaces/http/`：schema、路由和错误映射，禁止写合成业务逻辑。
- projects 域继续负责项目归属、资源归档与删除边界；复用已有任务和产物基础设施，不复制一套生成队列。

依赖保持 interfaces → modules → integrations / persistence / core。运行期锁、任务表和队列归 ApplicationContext 管理。独立渲染执行通道不占用 ComfyUI GPU 生成队列；默认并发 1，启动恢复、超时、取消和子进程回收通过现有生命周期管理。

同步第三方合成函数不得直接阻塞 HTTP 事件循环。优先受控子进程，以固定参数列表执行，不拼接 shell 命令。

## 7. 对外契约（拟议，尚未实现）

接口覆盖创建 / 查询成片、保存草稿、提交版本、任务状态 / 取消 / 重试、产物查询 / 下载、审核 / 交付。UI、HTTP 和 MCP 适配同一业务服务，不各自维护合成规则。

提交成功返回 task_id、film_id、version_id、project_id；查询返回状态、阶段、错误码和 artifacts。失败区分素材缺失、参数错误、依赖不可用、渲染失败、校验失败，不只返回进程退出码。

创建时显式 project_id 优先；未提供时沿用当前项目机制，创建后永久绑定，切换当前项目不能改变已有任务归属。提交请求支持幂等，避免重试重复渲染。

现阶段不增加工具或修改现有 AI 技能承诺，待后端可用后同步接口、MCP 和技能文档。

## 8. 文件、删除与安全

复用项目自动目录与归档服务，最终视频进入项目视频资源，方案、版本元数据和任务临时文件按现有存储约定管理，不引入用户自选任意输出路径。

- 文件写完并校验后原子发布，失败不得留下可误认的完成产物。

- 删除项目先终止关联渲染，再清理项目自有产物、临时文件与记录；不删除外部文件。
- 失败任务可重试，清理仅针对受控临时目录。已交付版本不可被后续任务覆盖。
- 限制并发、时长、尺寸、磁盘使用与进程执行时长；下载通过既有产物端点，不暴露任意本地路径。

## 9. 分阶段实施与验收

第一阶段（本次）：成片列表、编辑页交互、显式示例数据、移动端布局和本方案文档。无真实渲染。

第二阶段：持久化草稿与不可变版本、OpenMontage 基础镜头裁剪拼接 / 混音、独立渲染调度、取消恢复、项目归档和错误展示。以两个视频加一段配乐完整跑通。
