# Qwen Text to Image

Create a complete image prompt covering subject, scene, composition, light, palette, rendering style, and exclusions. Unless the user explicitly requests a stylized look, make the result realistic and cinematic with natural anatomy, physically plausible materials and lighting, crisp fine details, clean focus, coherent perspective, and a high-resolution finish. Preserve requested visible text exactly; if no text was requested, forbid decorative text and watermarks. Do not let a short prompt collapse into a generic low-detail or anime image.
