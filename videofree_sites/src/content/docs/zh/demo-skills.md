## <span class="no">1</span>准备两个完整技能文件夹

在 VideoFree Studio 项目的 `examples/skills/` 里找到下面两个目录，一起复制到你的智能体支持的技能目录。一定复制整个文件夹，不要只复制 `SKILL.md`。

```text
智能体的技能目录/
├─ dialogue-video-skill/  ← 负责策划、分镜、生成与审核
└─ openmontage/           ← 负责剪辑、混音和最终合成
```

媒体生成由主制片直接调用 VideoFree Studio 的 MCP，按下面第 3 步配置即可，不需要再安装其他媒体调用技能。

不同智能体的安装位置不一样，可以直接问它「你的技能安装目录在哪」。OpenMontage 的完整源码、AGPL-3.0 许可证和版权声明都要保留。

## <span class="no">2</span>让智能体检查环境和依赖

生成在 VideoFree Studio 这边进行，剪辑合成在智能体的运行环境进行。所以智能体那边也需要 Python 3.10+、FFmpeg 和 ffprobe，以及 OpenMontage 的 Python 依赖。下面这段可以直接发给它：

> 请帮我安装 videofree 的演示视频技能。我已准备 dialogue-video-skill、openmontage 两个完整文件夹。先确认当前智能体的技能安装目录，再复制完整目录并保留所有资产、脚本和许可证。检查 Python 3.10+、FFmpeg 和 ffprobe，在你实际使用的 Python 环境安装 openmontage 的 requirements.txt。给主制片配置我的 videofree MCP：【填网关地址，例如 http://192.168.50.8:8765/mcp】。刷新技能发现，校验固定资产和媒体能力，只检查，不要直接生成或花费额度。

选择 Remotion 或 HyperFrames 时，才需要额外安装对应 Node 依赖。普通 FFmpeg 合成不必先装所有渲染工具。

## <span class="no">3</span>连接 VideoFree Studio 的 MCP

在智能体的 MCP 配置里添加一个 HTTP 服务，名字可填 `videofree`，地址填 `http://你的网关电脑IP:8765/mcp`。它随 VideoFree Studio 一起启动，不用再单独开一个服务。

同机可以用 `http://127.0.0.1:8765/mcp`。另一台电脑必须用真实局域网 IP，例如 `http://192.168.50.8:8765/mcp`，不要照抄成自己的地址。

让智能体先检查健康状态、查询可用能力和预设音色。能查到才说明连接成功。各平台配置格式不同，参照当前智能体的 HTTP MCP 配置说明和 `dialogue-video-skill/references/install.md`，不要把某个平台的 JSON 当成通用格式。

::note
这套演示视频技能使用 MCP。请选用支持 HTTP MCP 的智能体，只给主制片配置媒体服务。
::

## <span class="no">4</span>刷新技能，让它检查能不能用

刷新或重启智能体，让它读到新技能。让它检查固定人物资产、工具链和下载权限，再跑 OpenMontage 的 preflight 检查。没有图像、视频或声音审核能力，就必须说明限制，不能假装已经审核通过。

支持子智能体时，只有主制片连接媒体生成工具；剧本、分镜和 QA 按任务给权限，别让每个子智能体都随意提交生成。权限隔离要在宿主设置，技能文字本身不能代替权限配置。

## <span class="no">5</span>先做一个短片，再开全自动

第一次先发这个例子，确认人物、声音、生成和合成都正常：

> 使用 dialogue-video-skill，制作一段机器人和青年男人对话讲解的视频，主题是「为什么天空是蓝色的」，30秒、9:16、保留对白、不加字幕。先告诉我制作方案、预计生成次数和是否二采，等我确认后再生成。

跑通后再授权全自动。把主题、时长、画幅、生成次数或费用上限、是否二采、哪些环节需要你确认说清楚。出现参考图身份不明确等问题，智能体仍应停下来问你，不能盲目确认。

例如：「方案确认，最多提交 12 次生成，允许二采；无歧义的步骤自动继续，有身份或预算问题先问我。」

## <span class="no">6</span>找到结果，保留制作记录

生成素材保存在 VideoFree Studio 的项目里。让智能体先创建专属项目，后续提交带项目 ID，避免和你手动生成的素材混在一起。

最终剪辑成片保存在智能体约定的交付目录，不一定在 VideoFree Studio 项目目录。开始前让它告诉你输出到哪里。每次制作使用独立工作目录，保留方案、素材清单和审核记录，不要往技能文件夹里堆成片。

想拆解这套技能的架构——定稿先行、阶段闸门、受控提交——做你自己题材的全自动流水线，见[全自动长视频技能开发](/guide/skill-dev/)。
